Esports Model Grader

Problem and intended users

People comparing esports statistics need more context than a single number. This project explores presenting recent player results, matchup information, and head-to-head history together.

My contribution and decisions

I have worked on the project interface and data workflow, including views for kills and headshots, recent-match windows, and matchup context. Clear labeling matters because a statistic can refer to one map or a two-map series.

This diagram describes the intended workflow; it is not an application screenshot.

Limits and next steps

Old match records and incomplete headshot data have been challenges. I want the tool to make data freshness and coverage easier to see. A projection is uncertain and does not guarantee an outcome.
